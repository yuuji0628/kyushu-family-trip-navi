v8.3.0｜FAMILY EDITORIAL

記事本文の作り方を大幅に変更しました。

主な変更:
- 「ホテル紹介」より「この家族が実際に泊まるならどうか」を中心に執筆
- 最初に「家族目線で見た強み」と「予約前の注意」を明示
- 0〜2歳 / 3〜6歳 / 小学生で見るポイントを分ける
- 客室は広さではなく、寝かしつけ・荷物・寝具・夜の過ごし方で評価
- 食事は豪華さではなく、子どもが食べられるか・夕方の移動を減らせるかで評価
- プールは「ホテル自体を旅の予定にできるか」で解説
- 温泉は子どもの眠気・夕食・入浴時間まで含めて解説
- 館内設備は抱っこ・ベビーカー・荷物を含めた移動目線で解説
- ホテル到着から就寝までの流れを想像する章を追加
- 料金は最安値ではなく家族全員の総額で考える章へ変更
- 口コミは家族構成が近い投稿を見る考え方へ変更
- 1泊2日はプール/温泉/食事の有無で文章を変える
- 最後に「合いやすい家族」「再確認したい家族」を具体化
- 同じホテルでもseedにより導入や年齢別コメントを変化

既存機能を維持:
CONTENT HASH DEDUPE / FRESH IMAGE REPAIR / SEO MAX /
写真起点記事 / Family Magazine / Nativeホテル検索 / Native Login /
Native記事作成 / Native削除 / GitHub ZIP / D1 / Cron

注意:
この変更は今後自動作成・手動作成されるホテル記事に適用されます。
既にD1に保存されている本文そのものは自動で書き換えません。

GitHubでは worker.js を置き換えてください。
