v8.0.1｜記事本文を読者向け表現へ整理

変更:
- 記事本文から「楽天トラベルAPI」「施設情報API」など内部システム名を非表示
- 「代用していません」「高解像度写真を取得できなかった」など制作側の事情を削除
- 「この記事の編集角度は〜」を削除し、普通の旅行メディア表現へ変更
- 写真キャプションを自然な表現へ変更
- 客室写真がない場合は、予約ページで部屋タイプごとの写真確認を案内
- 食事写真がない場合は、プランや時期による内容変更の案内に変更
- 既にD1に保存済みの記事も表示時に古い技術表現を自動クリーニング
- 新規記事も最初から読者向け表現で生成
