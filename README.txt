v7.9.0｜ホテル写真をカテゴリ別にできるだけ全掲載

変更:
- 楽天施設詳細レスポンス内の画像URLを再帰的に収集
- 客室 / 食事 / 温泉・風呂 / プール / 館内施設 / 宿泊プラン / その他 に分類
- 取得できた高解像度画像は同じURLを重複させず記事へ掲載
- 客室には客室画像だけを掲載
- 食事写真専用セクションを追加
- プールはプールカテゴリ、温泉は温泉カテゴリとして掲載
- 外観やプールを客室写真として代用しない
- サムネイルより元画像を優先
- 小さい画像を無理に画面幅まで引き伸ばさない
- 記事の4種類バリエーションは維持

楽天API側が返さない画像は掲載できません。
不明な画像は無理に客室・食事・プールと断定せず「その他」に回します。

GitHubでは worker.js を置き換えてください。
