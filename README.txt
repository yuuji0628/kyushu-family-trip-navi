v8.2.2｜画像表示を直接URL優先に修正

原因:
v8.2.1では記事画像をすべてWorkerプロキシ経由にしたため、
以前ブラウザから直接表示できていた楽天画像まで
Worker側取得で失敗してプレースホルダーになっていました。

修正:
- まず以前と同じく元の画像URLを直接表示
- 直接表示に失敗した画像だけWorkerプロキシへ自動切替
- プロキシも失敗した場合だけプレースホルダー表示
- 既存D1記事も表示時に自動で新方式へ変更
- SEO MAX、写真起点記事、管理画面、自動作成、D1、Cronは維持

GitHubでは worker.js を置き換えてください。
