九州ファミリー旅ナビ 楽天ホテル検索自動化 v6

Cloudflareシークレット:
- RAKUTEN_APPLICATION_ID
- RAKUTEN_ACCESS_KEY
- RAKUTEN_AFFILIATE_ID（設定済みなら自動でアフィリエイトURLになります）

使い方:
1. GitHubルート直下の worker.js を置き換える
2. デプロイ完了後 /admin.html にログイン
3. 記事編集の「🟥 楽天ホテル検索」でホテル名を入力
4. 「楽天で検索」
5. 正しい候補の「このホテルを使う」
6. 楽天トラベルURLが自動入力される
7. 記事を保存

利用API:
楽天トラベル キーワードホテル検索API 2026-07-31版
