v7.8.0｜客室写真の詳細取得＋記事内容バリエーション強化

今回の重要修正:
1. 楽天トラベル施設情報API（HotelDetailSearch 20260731）を記事作成前に追加取得
2. roomImageUrl / roomThumbnailUrl を正しく保存・記事生成へ渡す
3. 手動ホテル検索からの記事作成でも詳細APIを実行
4. Cronの完全自動記事でも同じ詳細取得処理を利用
5. 部屋・風呂・朝食・清潔さ等の詳細評価も取得可能な範囲で記事へ反映
6. 記事ごとに編集角度と構成を4種類から変化
   - 安心重視
   - ホテル滞在重視
   - 旅程重視
   - 比較・コスパ重視
7. H2の順番・見出し・導入・抜粋もホテルごとに変化
8. 外観写真を客室写真として代用しないルールは維持

注意:
楽天API側でroomImageUrl自体が空の場合は、客室画像は掲載しません。
その場合でも誤った外観画像を「客室」として表示することはありません。

既存機能維持:
ファミリー向け記事デザイン / Nativeホテル検索 / Native Login /
Native記事作成 / Native削除 / GitHub ZIP / D1 / Cron

GitHubでは worker.js を置き換えてください。
